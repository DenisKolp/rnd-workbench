# Project Context Router MCP

## Summary

The repository installs `mcp-project-context-router` as an exact lockfile-pinned development dependency. Codex starts its local stdio MCP server from `.codex/config.toml`, while `.project-context` stores durable project knowledge and a generated search index.

## Operating model

- Run `npm run context:index` after adding or promoting durable context.
- Run `npm run context:doctor` to validate the MCP configuration, records and ignore rules.
- Use context packs and search before implementation to recover architecture, decisions and integration boundaries.
- This MCP server supports development context collection. It is not embedded in the end-user `.app` and does not send assistant data to a remote service.
