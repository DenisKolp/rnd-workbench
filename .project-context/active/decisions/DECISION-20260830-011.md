# Explicit local-first LLM routing and recoverable user deletion

## Decision

Keep Whisper, OmniVoice, source storage, automation execution and the default
Qwen route local. Permit an external OpenAI-compatible LLM only after an
explicit user configuration. Remote endpoints require HTTPS, except loopback;
credentials are endpoint-scoped in macOS Keychain and never persisted by the
Python store. External context defaults to the current task, while workspace
scope requires a separate choice bound to the current endpoint and workspace.

Meeting audio is normalized with macOS `afconvert`, transcribed by local
Whisper and imported as a managed audio copy plus Markdown transcript before
deterministic meeting analysis.

Tasks, sources, meetings and artifacts are deleted only after native UI
confirmation. Database relations and indexes are removed transactionally;
managed copies move to macOS Trash, while original user-selected files remain
untouched. A failed database transaction restores files moved during the
attempt.

## Consequences

- Local and external routes are visually distinct and never silently replace
  each other.
- The exact remote disclosure is visible in settings before use.
- Background automations cannot leak workspace context through the external
  route.
- User deletion is recoverable for managed files and deterministic for related
  database state.
- Ad-hoc development signatures can change their designated requirement after
  a rebuild; stable Keychain access in distributed builds needs a persistent
  Developer ID identity.

## Verification

Python regression tests cover routing, cancellation, task/workspace scope,
audio import and deletion cascades. Swift typecheck and endpoint
canonicalization self-tests cover the native configuration and state guards.
Release evidence is recorded in `VERIFY-20260830-005`.
