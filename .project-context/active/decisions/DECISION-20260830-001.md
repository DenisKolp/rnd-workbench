# Reference-aware barge-in echo suppression

## Context

The energy-only barge-in detector learned speaker leakage during a short initial grace period. Later, louder TTS passages could exceed that static baseline and cancel the answer. The local task log showed four interruption events within 26 seconds, confirming repeated false positives.

## Decision

Feed the RMS envelope of each 30 ms output block into a thread-safe playback reference. While TTS is active, combine the calibrated microphone baseline, learned acoustic gain and recent playback level before accepting a near-microphone voice candidate.

The shipped defaults require 300 ms of sustained candidate speech, use a 600 ms
initial grace period, require RMS 0.032 while the speaker is active, apply an
echo multiplier of 2.1 and retain the playback reference for 500 ms across TTS
chunk boundaries. During thinking, when no speaker output exists, the extra
playback floor is not applied so interruption remains sensitive.

## Verification

The automated suite includes a 2.1-second streamed-echo regression that does not
interrupt, followed by a louder near-microphone signal that still interrupts in
300 ms. All 44 tests pass, and the signed v0.6.0 application contains the
updated runtime and configuration.
