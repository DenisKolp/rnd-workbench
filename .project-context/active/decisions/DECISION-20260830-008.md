# Exact chunk provenance with non-sticky hybrid retrieval

## Context

Source-level FTS found a relevant snippet but the model received the beginning
of the file. Automatically retrieved sources were also written into the durable
task relation, so incidental matches polluted later turns.

## Decision

Migrate to schema v3 with overlapping source chunks, FTS5 chunk indexing and
exact source character offsets. Rank candidates by a deterministic local hybrid
of FTS order, token coverage, title coverage, phrase match and fuzzy lexical
similarity. Pass the matched chunk and its offsets to the model.

Keep manually attached and explicit `@` sources durable. Treat automatic
retrieval as turn-scoped and never write it into `task_sources`. Reanalysis of a
meeting reconciles equivalent items so stable IDs and user-set `done` or
`superseded` statuses survive.

## Consequences

- The evidence shown to the model is the evidence the search actually matched.
- A task no longer accumulates unrelated automatic sources over time.
- Character offsets support precise citations; page-aware PDF deep links and a
  real multilingual embedding model remain future enhancements.

## Verification

Migration/backfill, chunk offsets, prompt excerpts, task isolation, explicit
source durability, non-sticky auto retrieval and meeting status preservation
are covered by regression tests. Fresh-database integrity and foreign keys are
clean.
