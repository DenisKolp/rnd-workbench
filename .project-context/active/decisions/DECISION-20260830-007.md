# Structured local meetings and explainable Attention Engine

## Context

Meeting skills previously produced only free-form LLM text. Decisions,
assignments, commitments, risks, questions, owners and deadlines could not be
filtered, compared or tied to an exact transcript span. Today and Inbox also
treated local events as an unranked list.

## Decision

Store meetings and meeting items as migrated SQLite entities. Analyse imported
transcripts locally and deterministically, recording the exact quote and
character offsets for each extracted item. Support participant/period filters,
item status, briefing, topic history and comparison between meetings.

Rank actionable local events with an explainable Attention Engine. Combine
urgency, severity, task state and meeting deadlines, deduplicate repeated
signals, preserve source links and expose the same ranked result on Today,
Inbox and the direct question «Что требует внимания?».

## Consequences

- Meeting facts are inspectable structured data rather than an opaque summary.
- Attention ordering can be explained without asking the LLM to invent a score.
- External Calendar and Synapse remain explicit missing integrations; manual
  transcript import is the local operating mode.

## Verification

Meeting extraction, exact source spans, reanalysis, comparison, briefing,
filters, Attention ranking and UI command contracts are covered by the Python
suite. The live database migrated in place with integrity and foreign-key
checks clean; a requirements document mistakenly classified as a meeting was
returned to document status without deleting its source.
