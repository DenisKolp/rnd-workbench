# Headroom-limited click-free TTS playback

## Context

The player sent model output through a hard `[-1, 1]` clip and started or stopped
each streamed phrase at an arbitrary sample value. Loud synthesis peaks could become
flat-topped, while abrupt edges could produce clicks that sounded like clipping.

## Decision

Apply configurable output headroom before playback, with a shipped gain of 0.86.
Use a stateful block limiter with an immediate attack, gradual release and a 0.94
ceiling instead of hard clipping. Add 6 ms fade-in and fade-out ramps at playback
boundaries, including cancellation, while preserving 30 ms interruption checks.

## Verification

Regression tests assert that non-finite samples are sanitized, peaks stay below
the ceiling without hard clipping, phrase edges reach zero, and cancellation still
aborts after the first 30 ms block. The full Python suite passes with 31 tests.
