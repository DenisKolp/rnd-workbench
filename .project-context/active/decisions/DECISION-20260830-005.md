# Grouped workbench navigation with functional visual hierarchy

## Context

The full workspace exposed eleven peer navigation items, which made the product
structure harder to scan and left the Today screen without one dominant way to
resume work. The task plan was available through secondary controls even though
it is essential feedback for an agent task. The interface also needed more
visual variety without adding decorative content unrelated to system state.

## Decision

Keep all eleven specification sections, but group them under Work, Knowledge,
Tools, Control and System. Persist the selected section across launches.

Give Today a branded hero with one resume/start action and a functional local
pipeline diagram showing Whisper, Qwen and OmniVoice readiness. Present recent
tasks and attention items as two distinct panels. Show the task plan directly in
the task header as numbered or completed steps instead of hiding it in a menu.

Use the Severstal-derived navy, blue, steel and red palette, SF Symbols and the
existing supergraphic. Visual elements must communicate navigation, model state,
progress or attention rather than act as unrelated decoration.

## Consequences

- The information architecture becomes easier to scan without removing a
  required section.
- Today has a primary continuation path and a visible explanation of the local
  voice pipeline.
- Task progress is visible without an extra click.
- Compact chat remains intentionally dense and needs a separate follow-up if its
  message history grows beyond the current small-window use case.
